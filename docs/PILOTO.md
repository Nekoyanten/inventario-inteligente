# Plan de prueba piloto

Objetivo: validar el sistema con los 5 negocios que confirmaron interés antes de lanzarlo.

## Duración: 4 semanas

| Semana | Actividad | Resultado esperado |
|---|---|---|
| 0 | Instalación y capacitación (1 h por negocio, presencial o videollamada) | Cuenta creada, productos importados desde Excel, usuarios creados |
| 1 | Uso diario del punto de venta y entradas | Todas las ventas registradas en el sistema |
| 2 | Primer conteo físico y primeras compras con «Qué comprar» | Diferencia de inventario medida; órdenes enviadas por WhatsApp |
| 3 | Uso de alertas y reportes | El empresario revisa el panel al menos 3 veces por semana |
| 4 | Entrevista de cierre y encuesta | Decisión de compra y lista de mejoras priorizada |

## Checklist de incorporación (por negocio)

- [ ] Registro con el tipo de negocio correcto
- [ ] Productos importados (plantilla de Excel) y revisados
- [ ] Proveedores con tiempos de entrega
- [ ] Usuarios por rol (administrador, vendedores, encargado)
- [ ] Conteo físico inicial para arrancar con el stock real
- [ ] App instalada en el celular del dueño
- [ ] Correo configurado para el resumen diario

## Qué medir

| Indicador | Cómo se obtiene |
|---|---|
| Uso | Ventas registradas por día (reporte Ventas) y días con ingreso |
| Precisión | Reporte «Precisión de pronósticos» al final del mes |
| Diferencias de inventario | Valor de la diferencia en el primer y el último conteo |
| Agotados | Número de productos agotados semana a semana (panel) |
| Satisfacción | Calificación 1–5 en «Enviar comentario» y entrevista final |
| Intención de pago | ¿Pagaría el plan Emprendedor / Negocio? ¿Cuánto? |

Los comentarios enviados desde la app quedan en el admin (**Comentarios**) con negocio, página y calificación.

## Encuesta de cierre (5 preguntas)

1. ¿Qué tan fácil fue usar el sistema? (1–5)
2. ¿Qué función le resultó más útil?
3. ¿Qué le faltó o le molestó?
4. ¿Tomó alguna decisión de compra distinta gracias al sistema? ¿Cuál?
5. ¿Pagaría por seguir usándolo? ¿Qué plan y a qué precio?
